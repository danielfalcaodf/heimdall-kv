# Contribuindo com o Heimdall KV

Obrigado pelo interesse em contribuir! Siga as diretrizes abaixo.

## Como contribuir

1. Abra uma issue descrevendo o problema ou feature.
2. Aguarde triagem antes de abrir um PR.
3. Fork o repositório e crie uma branch descritiva.
4. Siga os padrões de commit abaixo.
5. Abra um Pull Request com descrição clara.

## Padrão de commit

```
type(scope): descrição curta
```

Tipos: `feat`, `fix`, `docs`, `test`, `refactor`, `chore`.

## O que não aceitar

- Dados pessoais reais (CPF, RG, endereços, e-mails reais).
- Arquivos `.env` reais, chaves, certificados ou tokens.
- Código que exponha segredos em logs, buscas ou IA.
- Dependências sem avaliação de segurança.

## Segurança

Para reportar vulnerabilidades, veja [SECURITY.md](SECURITY.md).
